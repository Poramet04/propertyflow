# Resume project entry

## English

**PropertyFlow — Full-stack Real Estate CRM & Mortgage Platform**

- Built a full-stack property discovery and sales CRM using React, TypeScript, Node.js, Express, PostgreSQL and Prisma.
- Implemented JWT authentication and backend-enforced CUSTOMER, AGENT and ADMIN authorization with ownership-scoped data access.
- Developed a seven-stage Kanban pipeline, follow-ups, viewing appointments, activity history, loan application tracking and transactional deal closing.
- Created tested mortgage, affordability, pre-qualification, commission and deterministic property-matching services with responsible financial disclaimers.
- Prepared environment configuration, structured API errors, CI builds and technical/portfolio documentation for deployment readiness.

## ภาษาไทย

**PropertyFlow — แพลตฟอร์ม Full-stack สำหรับอสังหาริมทรัพย์ CRM และสินเชื่อ**

- พัฒนาแพลตฟอร์มค้นหาอสังหาริมทรัพย์และ CRM งานขายด้วย React, TypeScript, Node.js, Express, PostgreSQL และ Prisma
- สร้างระบบ JWT Authentication และกำหนดสิทธิ์ CUSTOMER, AGENT, ADMIN ที่ฝั่ง Backend พร้อมตรวจสอบเจ้าของข้อมูล
- พัฒนา Kanban Pipeline 7 ขั้นตอน ระบบติดตามงาน นัดชม Activity Timeline กระบวนการสินเชื่อ และการปิดดีลแบบ Transaction
- พัฒนาและทดสอบระบบคำนวณสินเชื่อ ความสามารถในการซื้อ Pre-qualification ค่าคอมมิชชัน และ Property Matching แบบ deterministic
- เตรียม structured errors, environment configuration, CI และเอกสารทางเทคนิคสำหรับการนำระบบไป deploy
